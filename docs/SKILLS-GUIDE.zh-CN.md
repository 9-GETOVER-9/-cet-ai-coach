# CET 四六级 AI 教练 · Skill 详细指南

> Skill 不是一个“万能聊天窗口”，而是一组职责清晰的备考教练。每个模块解决一个具体问题，并把训练结果沉淀为可追踪的本地记录。

---

## 1. 从“刷题”到“训练闭环”

很多同学在四六级备考中会遇到一种典型情况：做了不少题，也背了不少单词，但每周回顾时仍然说不清自己到底进步在哪里、最该补什么、下一次应该练什么。

CET AI 教练的设计重点不是增加题量，而是提高每次练习的反馈密度。

| 常见传统方式 | 容易出现的问题 | Skill 提供的改进 |
|---|---|---|
| 做一套题后只记录总分 | 总分变化不能解释具体短板 | 保存分项、题型、错因和耗时 |
| 写作只看范文 | 知道范文好，但不知道自己的问题 | 按内容、结构、语言、规范逐项批改 |
| 听力只循环播放音频 | 复听次数增加，但错因不清楚 | 将错误归类为干扰项、同义替换、数字时间、定位失败等 |
| 阅读只背单题答案 | 相似题再次出现时仍然容易错 | 积累定位词、同义替换和题型策略 |
| 词汇表从头背到尾 | 不会的词和已经掌握的词混在一起 | 分离每日推词、难词池、复习测试和已掌握词 |
| 计划一开始很完整，后续难坚持 | 没有依据实际进度动态调整 | 根据本地记录推荐下一步训练 |

### 训练闭环

```text
诊断当前水平
   ↓
找出最值得优先解决的问题
   ↓
调用对应 Skill 完成训练
   ↓
将训练结果保存到本地
   ↓
通过 Dashboard 查看趋势
   ↓
安排下一次练习
```

## 2. `/cet`：总入口与学习导航

### 它解决什么问题

当你不知道今天应该练什么，或者想快速了解自己目前的复习状态时，可以从 `/cet` 开始。它会读取本地档案，判断你是否已经完成首次摸底，并将需求路由到合适的子模块。

### 与传统方式的区别

传统复习常常从“今天想刷什么题”开始；`/cet` 更关注“当前最值得练什么”。它把目标分、剩余时间、历史练习和薄弱模块放在一起考虑。

### 适合的使用场景

- 第一次使用系统
- 一段时间没复习，想重新找节奏
- 不确定今天应该练写作、听力还是阅读
- 想查看当前进度和下一步建议

### 示例

```text
/cet
```

你也可以直接说：

```text
我准备考六级，目标 550 分，最近阅读还可以，但听力经常错很多。今天应该练什么？
```

## 3. `/cet-diagnose`：成绩诊断与备考计划

### 它解决什么问题

诊断模块把“我要过四级”或“我想冲 550 分”变成可执行计划。它会结合考试类型、目标分、考试日期、当前分项和每周可投入时间，给出优先级与短期任务。

### 与传统方式的区别

传统计划常常平均分配时间，例如每天都背单词、做阅读、听听力。诊断模块更强调资源分配：先解决最拖后腿、最有提分空间的问题。

### 输出内容

- 当前状态概览
- 距离目标分的差距
- 分项判断
- 最容易提分的模块
- 最拖后腿的模块
- 2–8 周训练计划
- 接下来 3 天的具体任务

### 推荐使用频率

- 备考开始时使用一次
- 每次完整模考后使用一次
- 每隔 1–2 周重新诊断一次

## 4. `/cet-writing`：写作批改教练

### 它解决什么问题

很多人会背模板，但真正写作时仍然容易出现跑题、结构松散、搭配不自然和句式重复。写作 Skill 不是只给一篇范文，而是先定位你的问题，再给升级路径。

### 与传统方式的区别

| 传统写作复习 | 写作 Skill |
|---|---|
| 背诵范文和模板 | 先判断题目要求与立场，再设计结构 |
| 自己很难发现语言问题 | 按段指出搭配、语法、连接和逻辑问题 |
| 只看到最终范文 | 同时提供原文问题、修改建议和目标分版本 |
| 写完后没有记录 | 保存主题、估分、字数、用时和错误标签 |

### 两种模式

**审题模式**：只提供作文题目，获得题目拆解、三段式提纲和可用表达。

**批改模式**：提供题目和自己的作文，获得结构化批改、分项估分、逐段建议和升级版本。

### 示例

```text
/cet-writing
请帮我批改下面这篇六级作文，目标是表达更自然、结构更清楚。
```

## 5. `/cet-listening`：听力错因分析教练

### 它解决什么问题

听力错误不一定只是“词汇量不足”。有时是被干扰项带跑，有时是没识别同义替换，有时是数字、时间、人名或态度题定位失败。听力 Skill 会把模糊的“没听懂”拆成可以训练的原因。

### 与传统方式的区别

| 传统听力复习 | 听力 Skill |
|---|---|
| 做完题只看正确答案 | 统计分题型表现与错因标签 |
| 反复播放音频但缺少重点 | 给出句听写、影子跟读和错题复听任务 |
| 错题之间彼此孤立 | 聚类共性问题，找出高频失误 |
| 难以看到长期趋势 | 保存正确率、估分、耗时和错因变化 |

### 常见错因标签

- 干扰项误判
- 同义替换未识别
- 数字与时间信息遗漏
- 人名、地名和专有名词干扰
- 信号词定位失败
- 态度与推断判断不准

## 6. `/cet-reading`：阅读精读教练

### 它解决什么问题

阅读训练不应该只停留在“这题选 B”。阅读 Skill 会分析选词填空、长篇匹配和仔细阅读的错误类型，帮助你建立更稳定的定位和判断策略。

### 与传统方式的区别

| 传统阅读复习 | 阅读 Skill |
|---|---|
| 逐题对答案 | 区分题型并记录正确率和耗时 |
| 只记住单题解释 | 提取同义替换、定位词和干扰项 |
| 做题速度难以管理 | 给出限时训练策略 |
| 错误模式不清晰 | 记录词性、定位、推断、干扰项等标签 |

### 三类重点题型

- `banked_cloze`：选词填空
- `matching`：长篇阅读 / 段落匹配
- `careful_reading`：仔细阅读

## 7. `/cet-translation`：汉译英翻译教练

### 它解决什么问题

翻译最常见的问题并不是单词不会，而是信息遗漏、中式英语、搭配不自然、句子过长和连接不清。翻译 Skill 会帮助你把“能翻出来”升级为“更准确、更自然”。

### 与传统方式的区别

| 传统翻译复习 | 翻译 Skill |
|---|---|
| 背诵参考译文 | 对照原文定位信息遗漏和表达问题 |
| 只积累零散词组 | 按主题沉淀高频表达 |
| 容易追求复杂长句 | 强调准确、清楚和可控表达 |
| 修改过程难以追踪 | 保存估分、错误标签和关键短语 |

### 两种模式

- **批改模式**：提供中文原文与自己的译文，获得分项反馈和升级版本。
- **素材模式**：只提供主题，获得常用词组、句型和一段练习材料。

## 8. `/cet-vocab`：词汇训练教练

### 它解决什么问题

词汇训练不是无限增加单词数量，而是不断区分“新词”“难词”“需要复习的词”和“已经掌握的词”。词汇 Skill 用本地文件维护一个简单但可追踪的复习系统。

### 与传统方式的区别

| 传统背词方式 | 词汇 Skill |
|---|---|
| 从单词书第一页背到最后一页 | 根据四级或六级水平推送更合适的词 |
| 会的词仍然反复出现 | 建立已掌握词记录 |
| 难词散落在笔记中 | 使用难词池集中复盘 |
| 背词和做题分离 | 可以结合阅读同义替换和听力场景词 |

### 可用模式

- 今日词汇
- 复习测试
- 阅读同义替换
- 听力场景词
- 难词复盘

## 9. `/cet-dashboard`：本地学习仪表盘

### 它解决什么问题

备考最难坚持的一点，是很难感受到“我到底有没有进步”。Dashboard 会读取本地学习记录，用趋势图和时间线帮助你回顾练习结果。

### 与传统方式的区别

传统笔记更适合记录单次练习；Dashboard 更适合观察一段时间内的变化，例如：

- 最近总分是否上升
- 哪个模块练习最少
- 哪类听力错因反复出现
- 写作或翻译估分是否稳定
- 词汇复习是否持续

### 当前页面

- 总览
- 分数趋势
- 写作
- 阅读
- 听力
- 翻译
- 词汇
- 时间线

## 10. 推荐使用方式

### 场景 A：刚开始备考

```text
/cet
→ /cet-diagnose
→ 按推荐模块完成第一次训练
→ /cet-dashboard
```

### 场景 B：写作和翻译较弱

```text
/cet-writing
→ 记录一篇作文的问题
→ /cet-translation
→ 积累一个主题表达表
→ 一周后重新练同类主题
```

### 场景 C：听力正确率不稳定

```text
/cet-listening
→ 找出错因 Top 3
→ 完成句听写与影子跟读
→ 重新做同类题
→ 对比错因是否减少
```

### 场景 D：每周复盘

```text
/cet-dashboard
→ 查看趋势
→ /cet-diagnose
→ 调整下一周重点
```

## 11. 数据主权与边界

本项目将学习档案保存在本地目录，使用 YAML Frontmatter + Markdown 记录。你可以使用文本编辑器查看、修改、备份或删除这些文件。

需要说明：

- AI 估分用于训练反馈，不代表官方成绩。
- 没有原文或音频时，Skill 应明确说明分析依据有限，不应编造内容。
- 本项目的本地记录不等于整个 AI 交互完全离线。
- 公开仓库中不要提交个人 `cet-data/` 目录。

完整数据格式见 [`../SCHEMA.md`](../SCHEMA.md)。
