CET 四六级 AI 教练

一套装在你自己电脑上的 CET-4/CET-6 备考工具：AI 教练 + 本地数据仪表板。
所有数据只在你电脑里，没有云端，没有账号。

7 个 Skill 模块 本地数据 · 零隐私风险 React + Express 仪表板 V1.0.0
01 / 痛点

四六级备考的困境

传统备考方式存在几个核心问题

📝

写了没人改

作文和翻译写完没有专业反馈，不知道自己的分数水平和具体问题在哪里，只能靠猜。

🎧

听力错因不明

听力做完只看到对错，不知道是因为干扰项、同义替换还是数字陷阱导致的错误。

📊

没有数据追踪

练了很多天但看不到进步趋势，不知道哪个模块最拖后腿，备考缺乏方向感。

☁️

隐私存疑

在线平台需要注册账号，学习数据上传云端，个人备考信息不受自己控制。

02 / 解决方案

七大 AI 教练模块

基于 Claude Code Skills 架构，每个模块是一个独立的 AI 教练。 用 /cet 命令一键调用， 教练会审题、批改、估分、分析错因，然后把所有数据沉淀到本地文件。

程序和数据完全分离。升级 Skill 不会删除你的学习数据。

✍️
写作教练
审题、批改、估分、范文升级
🎧
听力教练
错题分析、精听任务、错因聚类
📖
阅读教练
选词填空、长篇匹配、仔细阅读
🌐
翻译教练
汉译英批改、中式英语纠正
📚
词汇训练
每日推词、间隔复习、难词池
📈
诊断 + 仪表盘
成绩诊断、计划生成、可视化追踪

05 / 数据规范

标准化的本地数据架构

cet-data/
  ├─ profile.md ← 学员档案
  ├─ scores.md ← 成绩记录
  ├─ writing/
  │  └─ submissions/
  │     └─ YYYYMMDD_topic.md
  ├─ reading/
  │  ├─ submissions/
  │  └─ synonyms/
  ├─ listening/
  │  └─ submissions/
  ├─ translation/
  │  └─ submissions/
  └─ vocab/
     ├─ days/
     ├─ difficult.yaml
     └─ mastered.yaml

📋 YAML Frontmatter

每个提交文件头部包含结构化 YAML 元数据：日期、考试类型、分项得分、错因标签、用时等。Dashboard 直接解析这些元数据生成图表。

📄 Markdown 正文

Frontmatter 下方是给用户看的详细分析报告：逐题复盘、错因解释、改进建议、范文等。既是数据源也是阅读材料。

📐 SCHEMA.md 规范

所有 Skill 写入数据时必须遵守统一的 SCHEMA.md 规范。确保模块间数据格式一致，Dashboard 能可靠聚合所有数据。

💾 程序与数据分离

Skill 代码安装在 ~/.claude/skills/，学习数据存储在 cet-data/。升级不会丢失数据。

07 / 隐私与安全

你的数据，只在你手里

这不是一个 SaaS 产品。它是一个装在你电脑上的工具箱。 没有注册、没有云端、没有追踪。

所有学习数据以纯文本（YAML + Markdown）存储在你指定的本地目录。 你可以随时用任何文本编辑器查看、修改、备份、删除。

🚫

零网络依赖

数据写入和读取全部在本地文件系统完成，Dashboard 不发送任何网络请求。

📁

纯文本存储

YAML + Markdown 格式，没有数据库、没有二进制文件，人类可读可编辑。

🔑

数据可迁移

整个 cet-data 目录可以复制、Git 管理、跨设备同步，完全由你控制。

♻️

程序数据分离

升级或重装 Skill 不会影响已有的学习数据，二者物理隔离。

npm install && npm start
